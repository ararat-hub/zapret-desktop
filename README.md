# Zapret Desktop

Приложение Windows для подбора и запуска штатных пресетов [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Интерфейс, движок Zapret, WinDivert и пресеты входят в один `ZapretDesktop.exe`. Встроенный пакет можно установить без доступа к GitHub.

[Скачать ZapretDesktop.exe для Windows x64](https://github.com/ararat-hub/zapret-desktop/raw/refs/heads/main/downloads/ZapretDesktop.exe)

## Первый запуск

1. Нужны Windows 10/11 x64 и [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).
2. Сохраните **ZapretDesktop.exe** в постоянную папку и откройте его.
3. Нажмите **Установить и подобрать**. Если приложение нашло уже установленный Zapret, подтвердите использование его файлов. Для портативной копии нажмите **Выбрать локальную папку** и укажите папку с `service.bat` и `bin`. При отсутствии локальной копии приложение предложит встроенный пакет. После подтверждения UAC нужные файлы будут скопированы в Program Files. Загрузка с GitHub для этих вариантов не требуется.
4. Для следующих запусков выберите **Discord и YouTube**, **Discord** или **YouTube** и нажмите **Подобрать и включить**. Первый пресет, который дважды проходит сетевую проверку выбранных сервисов, остаётся включённым. Приложение запоминает его и проверяет первым в следующий раз.
5. Чтобы выбрать пресет самостоятельно, используйте выпадающий список и кнопку **Включить**. **Остановить** и закрытие приложения завершают запущенный им процесс движка.

Для Discord проверяются публичный API и ответ Hello по WebSocket. Для YouTube проверяются сайт и загрузка обложки с CDN. Карточки сервисов показывают результат, а журнал содержит подробности по каждому пресету. Голосовой чат и воспроизведение видео проверяются в самих сервисах.

Перед подбором или ручным запуском приложение временно останавливает работающую службу `zapret`. Служба запускается снова при отключении пресета, закрытии окна, отмене или неудачном подборе. Если служба уже была остановлена, её состояние сохраняется. Windows может запросить права администратора.

## Обновления и автозапуск

- Проверка стабильного релиза выполняется при запуске приложения и раз в четыре часа, пока оно работает. Её можно отключить в настройках или запустить вручную.
- Когда появляется новая версия, в окне отображается кнопка **Установить** с номером версии. Скачивание начинается после подтверждения в диалоге. Приложение сверяет SHA-256 архива с данными GitHub перед распаковкой. Если пресет уже работает, новая версия используется при следующем подключении.
- **Запускать последний пресет при входе** запускает пресет, который последним прошёл проверку выбранных сервисов. После входа окно остаётся в трее. Если сохранённого пресета ещё нет или он исчез из текущей версии движка, откройте окно и выполните подбор.
- Двойной щелчок по значку в трее открывает окно. **Выход** в меню значка завершает приложение и восстанавливает старую службу, если приложение её остановило.
- При включении или выключении автозапуска Windows может запросить права администратора. При следующих входах задача Windows запускается без запроса UAC. Если автозапуск был настроен в старой версии, включите его один раз в новой сборке.

## Сборка из исходников

Для сборки нужен [.NET 10 SDK x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Для публикации EXE с автозапуском также нужны Visual Studio Build Tools с компонентом **Разработка классических приложений на C++** и Windows SDK. Выполните команды в корне проекта.

~~~powershell
dotnet build .\src\ZapretDesktop\ZapretDesktop.csproj -c Release
dotnet run --project .\tests\ZapretDesktop.Checks\ZapretDesktop.Checks.csproj -c Release
.\build\Publish.ps1
~~~

Готовый файл появится в папке `artifacts\win-x64`. Скрипт сборки проверяет SHA-256 архива по [манифесту пакета](build/flowseal.json) и встраивает официальный архив с лицензиями. Для запуска EXE нужен Desktop Runtime 10. У этой сборки отсутствует цифровая подпись издателя.

## Хранение и удаление

Настройки текущего пользователя находятся в `%LOCALAPPDATA%\ZapretDesktop\settings.json`. Версии движка хранятся в `%ProgramFiles%\Zapret Desktop\engine`. Задача автозапуска использует копию программы из `%ProgramFiles%\Zapret Desktop\startup`. Чтобы удалить оболочку, выключите автозапуск, закройте приложение и удалите EXE. Папки `startup` и `engine` можно удалить с правами администратора, когда их больше не используют другие учётные записи. Windows управляет загрузкой драйвера WinDivert.
